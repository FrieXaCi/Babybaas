Commando's
npm run dev — start de dev-server (Turbopack) op http://localhost:3000. Er kan slechts één next dev proces per project draaien; een tweede instantie sluit af met de melding "Another next dev server is already running" en toont de actieve PID.
npm run build — maakt de productie-build (inclusief type-checks).
npm run start — start de productie-build.
npm run lint — voert ESLint uit (flat config, eslint-config-next core-web-vitals + typescript).
npx tsc --noEmit — voert alleen de type-check uit.

Regels:
Expliciete ID's: Geef bij elke Neon MCP-aanroep altijd zowel de project_id als de branch_id expliciet mee. Laat de branch_id nooit weg: de standaardbranch van het project is productie, dus een aanroep zonder ID wordt uitgevoerd op de productie-omgeving.
Productie Bescherming: Voer nooit queries, migraties of schema-wijzigingen uit op de productie-branch (quiet-thunder-73262874), tenzij ik in een specifiek verzoek expliciet om de productie-omgeving vraag.
Destructieve Acties: Vraag altijd om toestemming voordat je een destructieve operatie uitvoert (DROP, DELETE, TRUNCATE, of het verwijderen/resetten van een branch), zelfs binnen de development-omgeving.
Schema Wijzigingen: Schema-wijzigingen verlopen via prisma migrate dev en niet via ruwe SQL middels de MCP (zie de sectie Database in coding-standards.md).
