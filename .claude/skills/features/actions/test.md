# Test Actie

1. Lees `current-feature.md` om te begrijpen wat er is geïmplementeerd binnen de Babybaas context.
2. Identificeer de server actions en utility functies die voor deze feature zijn toegevoegd of gewijzigd.
3. Controleer of er al tests bestaan voor deze functies.
4. Schrijf unit tests voor functies met testbare logica die nog geen tests hebben:
   - Maak unit tests met behulp van Vitest.
   - Richt je op server actions en utilities (geen componenten).
   - Test zowel de 'happy path' als de foutscenario's.
   - Schrijf tests alleen waar ze waarde toevoegen; gebruik je professionele oordeel.
5. Voer `npm test` uit om te verifiëren dat alle tests slagen.
6. Rapporteer de testdekking voor de nieuwe code van deze feature.
