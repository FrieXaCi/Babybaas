# Voltooi Actie

1. Voeg alle wijzigingen toe en commit deze met een duidelijke beschrijving.
2. Schakel over naar `main` en voeg de feature branch samen (nog niet pushen).
3. Verwijder de lokale feature branch.
4. Reset `current-feature.md`:
   - Wijzig H1 terug naar `# Huidige Feature`.
   - Maak de secties Doelen, Todo en Notities leeg (behoud de tijdelijke aanduidingen/comments).
   - Voeg een samenvatting van de feature toe aan het EINDE van de Geschiedenis (History).
5. Commit de reset: `chore: reset current-feature.md after completing [feature]`.
6. Push `main` EENMALIG naar origin (één push met alle wijzigingen).
7. Als de feature branch eerder gepusht was, verwijder deze dan ook van origin.
