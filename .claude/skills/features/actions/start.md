# Start Actie

1. Lees current-feature.md - controleer of de Doelen (Goals) zijn ingevuld.
2. Indien leeg, foutmelding: "Voer eerst /feature load uit".
3. Zet de Status op "In uitvoering".
4. Maak de feature branch aan en check deze uit (leid de naam af van de H1-kop).
5. Maak een lijst van de doelen en implementeer deze één voor één.
6. Werk de Todo-checklist af en markeer elk item als voltooid `- [x]` in current-feature.md zodra het klaar is.
